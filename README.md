# 🎨 Loknath Art Centre 🦚

A premium, modern website for **Loknath Art Centre**, a professional drawing school.

Built using modern web technologies with beautiful animations, responsive design, and an admin management system.

---

## 🚀 Tech Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- GSAP
- Radix UI
- Lucide React
- Embla Carousel

---

## ✨ Features

### Public Website

- Premium landing page
- Sticky glassmorphism navbar
- Hero section with Bengali typography
- Animated statistics
- About section
- Courses section
- Artwork gallery with category filter
- Featured artwork carousel
- Shop section
- Events section
- Blog section
- FAQ accordion
- Contact form
- Google Maps integration
- Newsletter subscription
- Dark/Light mode
- Fully responsive design
- SEO optimized

---

### Admin Dashboard

- Admin Login
- Manage Courses
- Manage Students
- Manage Teachers
- Fee Management
- Blog Management
- Product Management
- Reports Dashboard
- Image Upload
- Edit/Delete Records

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/your-username/loknath-art-centre.git
```

Go inside the project

```bash
cd loknath-art-centre
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```

---

## 🏗 Production

Build the project

```bash
npm run build
```

Start the production server

```bash
npm start
```
